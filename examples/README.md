# Bilingual layout sample / 双语排版示例

The source is an invented test fixture with manually supplied translations. The bilingual PDF is actual PaperPair engine output. The page images render that same output; they are not application UI screenshots. This is a layout demonstration, not a scientific result or translation benchmark.

- [synthetic-source-en.pdf](synthetic-source-en.pdf)：项目自建的英文测试文档，1 页。
- [bilingual-reading-zh-en.pdf](bilingual-reading-zh-en.pdf)：PaperPair PDF 引擎实际导出的中英阅读稿，2 页。

文档中的内容和图形均为排版测试而设计，译文由人工提供。它不是实际研究成果，不包含用户论文，也不能作为模型翻译质量的证明。

原始样例包含双栏文字、一个简单示意图和一个独立公式。导出稿用连续的中英对应行组织文字，并保留图形与公式。文字可以选中和复制。

README 中的两张页面图来自同一份导出 PDF，未替换内容或伪装成应用截图。示例文件元数据已检查，不包含本机路径、私人作者信息或嵌入附件。
